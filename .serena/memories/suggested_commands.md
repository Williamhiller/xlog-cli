# Suggested commands
- `rtk npm run dev:viewer` — run local viewer dev workflow.
- `rtk npm run dev:viewer:ui` — run Vite UI only for `viewer-react`.
- `rtk npm run build:viewer` — build viewer assets into `viewer-react/dist`.
- `rtk npm test` — run Node test suite (`node --test test/*.test.js`).
- `rtk npm run serve` — start xlog server.
- `rtk rg -n "pattern" viewer-react/src` — fast scoped search.
- `rtk git diff -- <path>` — inspect changes for one file.
